# Remix of Stock Buddy

Crie um módulo completo de controle de estoque com:

Campos do produto:

- Código

- Nome

- Descrição

- Categoria

- NCM

- Localização física (rua, prateleira, nível)

- Quantidade atual

- Quantidade mínima

- Valor de custo

- Valor de venda

- Data de entrada

- Última movimentação

Funções:

- Entrada manual de estoque

- Saída manual

- Saída automática ao concluir pedido

- Histórico de movimentações

- Alerta de estoque baixo

- Filtro por produto, data e categoria

- Exportação para CSV

Atualização automática do saldo.
